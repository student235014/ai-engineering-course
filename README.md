# ai-engineering-course

## Troubleshooting

### `'ascii' codec can't encode characters` при вызове GigaChat
**Что видела:** после того, как в `.env` был вписан сломанный ключ с русскими буквами, скрипт падал с ошибкой кодировки `ascii`.
**Почему:** в `GIGACHAT_CREDENTIALS` попали русские буквы, а значение ключа уходит в HTTP-заголовок `Authorization`, где допустима только латиница и цифры. ASCII-кодировка не может закодировать кириллицу.
**Что сделала:** вернула настоящее значение ключа (латиница + цифры). Дополнительно убедилась, что благодаря добавленному fallback (`try/except` в `ask_llm`) скрипт больше не падает, а автоматически переключается на `[HuggingFace]`.

### `401 Unauthorized` от HuggingFace
**Что видела:** после настройки fallback запрос уходил в HuggingFace, но возвращался с ошибкой `401 Unauthorized` — `Invalid username or password`.
**Почему:** в `.env` был указан неверный или устаревший `HF_API_KEY`. Возможные причины — токен отозван, перепутаны имена переменных или в значении есть лишние пробелы/кавычки.
**Что сделала:** перевыпустила токен на huggingface.co (Settings → Access Tokens), убедилась, что у него включено право **«Make calls to Inference Providers»**, и вставила новое значение (начинается с `hf_`) в `.env` без кавычек.

### `ModuleNotFoundError: No module named 'gigachat'`
**Что видела:** при запуске `python llm_client.py` Python не находил модуль `gigachat`, хотя библиотека была в `requirements.txt`.
**Почему:** не было активировано виртуальное окружение `.venv` либо скрипт запускался из другой папки, где `.venv` не подхватывается.
**Что сделала:** активировала окружение командой `.venv\Scripts\activate` (в начале строки терминала появилось `(.venv)`), перешла в папку `module_01` через `cd module_01` и запустила скрипт заново.
